股票易 隐私政策

最后更新：2026年3月7日

概述

股票易（StockEasy）是一款浏览器股票行情查看插件。我们高度重视用户隐私，本政策说明插件如何收集和使用信息。

数据收集

本插件不收集、不存储、不传输任何用户个人信息。具体来说：

  • 不收集用户的姓名、邮箱、电话等个人身份信息
  • 不收集浏览历史、Cookie 或网页内容
  • 不使用任何分析或追踪工具
  • 不与任何第三方共享数据

本地存储

插件使用浏览器本地存储（chrome.storage.local）保存以下数据，这些数据仅存在于用户本地设备上：

  • 用户添加的自选股票列表和分组
  • 用户设置的成本价和持仓数量
  • 插件显示偏好设置
  • 行情数据缓存（定期更新）

网络请求

插件仅向东方财富公开 API 发送请求以获取股票行情数据，请求中不包含任何用户个人信息。

权限说明

  • storage：用于在本地保存自选股和设置
  • alarms：用于定时刷新行情数据
  • host_permissions：仅用于访问东方财富行情 API

变更

如隐私政策有变更，将在插件更新中说明。

StockEasy Privacy Policy

Last Updated: March 7, 2026

Overview

StockEasy is a browser extension for viewing China A-share stock quotes. We take user privacy seriously.

Data Collection

This extension does not collect, store, or transmit any personal user information:

  • No personal identifiable information (name, email, phone) is collected
  • No browsing history, cookies, or webpage content is accessed
  • No analytics or tracking tools are used
  • No data is shared with third parties

Local Storage

The extension uses chrome.storage.local to save user preferences locally on the device:

  • Watchlist stocks and groups
  • Cost price and position quantity settings
  • Display preferences
  • Cached market data

Network Requests

The extension only sends requests to public Eastmoney APIs to fetch stock market data. No personal information is included in these requests.

Permissions

  • storage: Save watchlist and settings locally
  • alarms: Schedule periodic data refresh
  • host_permissions: Access Eastmoney market data API only
