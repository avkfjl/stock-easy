# 截图文件说明

请将以下截图放到此目录：

| 文件名 | 说明 | 建议尺寸 |
|-------|------|---------|
| `logo.png` | 插件 Logo | 128×128 px |
| `popup-main.png` | 主界面截图（股票列表+左侧栏） | 1280×800 px |
| `popup-detail.png` | 个股详情截图（分时/K线） | 1280×800 px |
| `mini-window.png` | 迷你窗口截图 | 300×400 px |

截取方法：
1. 打开插件 Popup，按 F12 打开开发者工具
2. Ctrl+Shift+P 输入 "screenshot"，选择 "Capture screenshot"
3. 裁剪保存到此目录
